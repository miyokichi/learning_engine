# Learning Engine v0.3 チュートリアル

## 1. LLMなしで学習の仕組みを体験する

インストール後、プロジェクトルートで実行します。

```powershell
.\.venv\Scripts\learning-engine.exe --db tutorial.sqlite3 tutorial
```

すべて架空のVia教材です。回答・承認も架空で、実際の専門家レビューではありません。各画面の内容に同意して教材を進める場合だけ `確認` と入力します。Enterで中断でき、同じDB・コマンドで再開できます。

## 2. 7つの短い画面

1. **過去の判断**：材料OXIDE_Aならモデル再利用、という教材用の初期ルールを準備します。
2. **Unknown**：新案件の材料が未確認なので、`判断：ASK / 理由：材料が未確認です。資料で材料を確認できますか？` と表示します。
3. **回答確認**：教材の資料回答を確認すると、`判断：REUSE_MODEL / 状態：EXECUTE` になります。これは内部の判断継続で、外部操作は行いません。
4. **訂正と対比**：`比較：過去は形状同等性=true、今回はfalse。` を確認し、再検証の例外草案を作ります。`回帰違反：0件。公開前です。` と表示します。
5. **公開と応用**：別の確認で公開すると、`未経験案件の判断：REQUIRE_VALIDATION。過去の正しい再利用判断も維持されました。` と表示します。
6. **自然言語の報告**：断面確認と形状計算の原文・手順候補を保存し、検証根拠を追加質問します。
7. **候補の承認**：手順を参考候補にします。`保存状態：ルール=公開済み、手順=approved_candidate、必須順序=unknown、実行不可。` と表示します。

教材は再実行しても重複しません。別教材として最初から試す場合は、新しいDB名を指定してください。

## 3. 日本語会話の固定練習

次は自由な自然言語理解を装うものではなく、決まった文章だけを解釈するオフライン教材です。空の教材DBで始めます。

```powershell
.\.venv\Scripts\learning-engine.exe --db chat_practice.sqlite3 chat --sample
```

画面には利用できる練習文を表示します。次の順番で、一行ずつ入力してください。`確認` は画面に表示された対象を確認する操作です。

```text
モデルの再利用を判断したい。材料はAで形状は同じです。
確認
この材料Aなら再利用できる。材料を条件として覚えて。
確認
確認
別の案件です。材料はA、形状の同等性は未確認です。
確認
断面を見たら同じでした。
確認
見直すと形状が違いました。再利用を保留して再検証してください。
確認
確認
次の案件も材料はAで形状が異なります。
確認
断面を確認してから形状計算をしました。形状差が理由で、判断は保留しました。
確認
確認
/exit
```

最初はREVIEWです。材料の初期ルールを承認した後、次案件では形状の確認が必要という仮説からASKになります。回答を確認するとEXECUTE。訂正・対比・回帰・公開後、次案件にREQUIRE_VALIDATIONを適用します。作業報告は参考候補のままで実行しません。

この入力を自動再生する場合は、別の空のDBに対して次を実行できます。回答と承認もすべて教材の架空データです。

```powershell
$env:PYTHONIOENCODING = "utf-8"
$OutputEncoding = [System.Text.UTF8Encoding]::new()
Get-Content -Encoding UTF8 examples/chat_sample.txt | .\.venv\Scripts\learning-engine.exe --db chat_practice_auto.sqlite3 chat --sample
```

再実行で既存の練習会話を選ぶ画面になった場合は、空の別DBを指定して最初から試してください。既存の会話を再開する場合は通常のchat起動で番号を選びます。

## 4. 逐次学習を比較する

```powershell
.\.venv\Scripts\learning-engine.exe replay-experiment --scenario examples/replay_sequence.json
```

Caseの公開、判断、回答の開示、正解の開示、訂正、公開を順番に再生します。`--db` に指定した本番DBは開きません。隔離された一時SQLiteは終了時に削除します。

`baseline_llm_plus_cases` は既定では単純な過去事例参照の固定モデル、`learning_engine` はルール・質問・確認を使います。両方に同じ公開済み情報を与えます。testの正解は推論後の採点にだけ使います。

出力には各時点で見えていたCase・レビュー済みCase・ルール、質問、実際に開示した回答、指標の分母を含めます。少数の架空ケースでの比較であり、実LLMや実業務の精度の証明ではありません。

## 5. 自分の仕事へ

自分用のDBを指定して、LLMを設定したchatを起動します。

```powershell
.\.venv\Scripts\learning-engine.exe --db my_learning.sqlite3 chat
```

最初は一件の作業報告からで構いません。「何を、なぜ、どの条件で、結果どうだったか」を話し、解釈を確認してください。設定・承認・再開の詳しい説明は [使い方ガイド](USER_GUIDE_ja.md) にあります。
